### 개요
닌자 키위의 고급 도전 API를 조회해서 최신의 고급 도전을 디스코드 봇으로 받는 서비스 입니다.

### 실행 방법

디스코드 봇 토큰과 보내고 싶은 채널 ID 준비 후 `.env`파일에 다음과 같이 작성

```
TOKEN = <Your Token Is Here>
CHAN_ID = <Your Channel ID Is Here>
```

``` shell
pip install -r requirements.txt
python app.py
```
